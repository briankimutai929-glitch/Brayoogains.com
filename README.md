# SMM Panel

A Social Media Marketing (SMM) Panel built with Node.js, Express, and MySQL.

## Features

- User registration and login
- Admin dashboard
- Service management
- Order management
- Wallet system
- API integration
- Secure authentication using JWT

## Project Structure

```
smm-panel/
├── config/
├── controllers/
├── database/
├── middleware/
├── models/
├── routes/
├── public/
├── server.js
├── package.json
└── README.md
```

## Installation

```bash
npm install
npm run dev
```
